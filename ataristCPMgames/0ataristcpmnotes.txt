CPMtools diskdef:

diskdef ataristcpm
  seclen 512
  tracks 80
  sectrk 9
  blocksize 2048
  maxdir 128
  skew 0
  boottrk 2
  os 2.2
end

Workflow: 'Load' source .HFE into HxC, export as .IMG. (R/O .IMD won't work).
Edit .IMG with CPMtoolsgui using diskdef from above, 'Load Raw image' in HxC with .IMG using settings from above, 'Export' as .MFM. This system works with .IMGs, but they seem unstable so conversion to .MFM is recommended.

Autostart: I made the Atari ST CP/M emulator autostart using 'INSTALL' in TOS 1.04 (disk image must be R/W, use .IMG, or .MFM). I used CPMtoolsgui to place SUBMIT.COM and PROFILE.SUB onto the game disk images. I don't even know if these disk images are bootable, because of this weird setup they don't need to be. Most of the automation is done through MAME (changing to drive B: and invoking SUBMIT PROFILE). 


MAME286 command line:

mame st -bios tos104 -flop "[path to tos cp/m emulator disk image]" -wd1772:1 35dd -flop2 "[path to cp/m game disk image]" -w -skip_gameinfo -autoboot_delay 9 -autoboot_command "\nb:\nsubmit profile\n"
